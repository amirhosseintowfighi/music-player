# ADR-0002: توپولوژی هیبرید — core در ایران، edge در خارج

- وضعیت: پذیرفته

## زمینه
کاربران ایرانی‌اند (تأخیر و فیلترینگ)، درگاه‌های ایرانی IP داخلی می‌خواهند، ولی تلگرام از ایران قابل‌اتکا نیست و لاگین اکانت از IP ایران ریسک بن دارد.

## تصمیم
- **core (ایران):** Postgres، Redis، Meilisearch، api، bot، worker، payments، admin.
- **edge (خارج):** indexer، streamer، tg-egress (webhook ورودی + Bot API خروجی)، کش استریم.
- ارتباط: WireGuard + mTLS.
- بایت‌های صوت **مستقیم از edge به کاربر** می‌روند، نه از طریق ایران.

## گزینه‌های ردشده
- همه در خارج: p95 زیر ۲۰۰ms برای کاربر ایرانی تضمین‌شدنی نیست؛ درگاه ایرانی مشکل دارد.
- همه در ایران + پروکسی: لاگین اکانت‌ها از ایران؛ تک‌نقطهٔ شکست.
- استریم از طریق ایران: ترافیک ×۳ — با بودجه نمی‌خواند.

## پیامدها
- قطعی تونل نباید پخش را قطع کند → توکن استریم به‌صورت آفلاین اعتبارسنجی می‌شود (ADR-0004).
- فیلترشدن IP لبه یک ریسک است → چند edge با چرخش از جدول `edge_nodes`.
